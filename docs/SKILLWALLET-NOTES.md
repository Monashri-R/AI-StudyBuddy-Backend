# SkillWallet submission notes

This repository is intended for the AI StudyBuddy backend portion of the SkillWallet capstone.

Before adding it to the official project workspace:
1. Confirm with the team which stories/epics this backend satisfies.
2. Run and test the backend locally.
3. Connect MongoDB Atlas.
4. Configure Gemini API securely using `.env`.
5. Do NOT commit `.env`, passwords, MongoDB credentials, or API keys.
6. Add the repository URL and project demo URL in SkillWallet after the team has tested them.
